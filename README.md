## Лабораторна робота 3. Метод опорних векторів (SVM) в системах машинного навчання
 
- **Мета:** реалізувати метод опорних векторів для виявлення мережевих атак на IoT-пристрої, оцінити точність моделі та дослідити фактори, що на неї впливають.
- **Завдання:** реалізувати алгоритм SVM на датасеті Kaggle (розділ *security*), оцінити точність та фактори, від яких вона залежить (масштабування, ядро, параметри `C` і `gamma`, розмір вибірки, набір ознак, баланс класів).
- **Датасет:** [Network IoT Dataset](https://www.kaggle.com/datasets/amineipad/ioittt) — записи мережевих з'єднань IoT-середовища, бінарна класифікація (норма / атака), ≈ 211 тис. записів.
- **Файл:** [`svm-iot-network-attacks_lab-3.ipynb`](svm-iot-network-attacks_lab-3.ipynb)
